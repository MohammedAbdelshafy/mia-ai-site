Specialist routing

A connected system could route each task to the most suitable tool or person. This page does not itself run that routing.

Connected tools

Tools and connectors must be configured, permissioned and tested individually before they can perform work.

Verification gate

Review outputs against stated requirements before calling a task complete. The page does not independently verify an output.

Mission visibility

A live implementation could show the plan and status for human review; this page is a design example.

Example workflow: Understand the request → plan the steps → choose tools → do the work → review the result → hand it back.
