# Mia AI CONTEXT

One job: present the current Mia concept honestly and help visitors understand what the demo does and what is not live yet.

## Inputs
- Public home: [index.html](index.html)
- Plans: [pricing.html](pricing.html)
- Full context and limitations: [README](README.md)
- Assets: [mia-muse-assets](https://github.com/MohammedAbdelshafy/mia-muse-assets)

## Process
1. Explain the outcome in plain language, without inflated autonomous-agent claims.
2. Label scripted interactions as demo/simulated.
3. Distinguish the public site, waitlist API, private preview and any live connected-tool runtime.
4. Keep planned prices and unavailable features clearly labeled.
5. Verify links, forms, responsive behavior and the server's protected routes before a release.

## Output
An understandable public product page and an honest path to request early access.

## Check
The claims on the site must match the running code, data path and billing state. A cinematic animation is not evidence that a task executed.
